# Aryaman Shah — Personal Portfolio

A personal resume/portfolio site for Aryaman (Aryan) Shah, a Computer Science student at UMass Lowell. Built as a single-page React app showcasing background, education, projects, and work experience.

## Tech Stack

- **React 19** + **Vite 7**
- **Tailwind CSS** for styling
- **Framer Motion** for scroll-triggered animations
- **react-icons** for iconography

## Features

- **Navbar** — sticky navigation with scroll-spy active-section highlighting and a responsive mobile menu
- **Hero** — animated intro with Framer Motion fade-ins and decorative blob shapes
- **About** — bio, skills grid, and a contact card with links to email, LinkedIn, GitHub, and a downloadable resume PDF
- **Education** — degree info with an expandable full coursework list
- **Projects** — project cards, including Smart Email Sorter (an ML classifier using TF-IDF + Naive Bayes)
- **Experience** — timeline of internship experience at Uplifty AI (React Native / Android development)

## Getting Started

```bash
git clone https://github.com/Aryan2521-04/personal-resume.git
cd personal-resume
npm install
npm run dev       # start dev server
npm run build     # production build
```
